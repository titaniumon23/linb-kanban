# User preferences for future Obsidian plugins

- Follow Obsidian's active colors and typography, with restrained corners. Do not blindly inherit mobile pill radii for text areas or large form fields.
- Treat desktop, iPad and iPhone as first-class: portrait/landscape, narrow split panes, touch/pointer/keyboard, virtual keyboard, safe areas, scroll, reachable save controls, and focus preservation.
- Core actions must have visible touch controls; hover/right-click cannot be the only entry point.
- Follow Obsidian's language automatically: Chinese and English UI, preserving user-written content.
- Use seamless interactions and preserve drafts, undo paths, data compatibility, offline fallbacks and ordinary Markdown behavior.
- Test meaningful lifecycle/data regressions and inspect representative desktop/tablet/phone layouts. Clearly distinguish emulated checks from physical device verification.

Keep marked Markdown and historical board formats compatible. Opening or upgrading must not rewrite user notes. Update only plugin files; never remove note or attachment files during updates.
